# 🎓 Nexivora — The Global Academic Collaboration Network

> **Connecting Learning, Innovation, People & Opportunities in One Ecosystem.**

🌐 **Live Website**: [https://shreyasshinde619.github.io/Nexivora/](https://shreyasshinde619.github.io/Nexivora/)

Nexivora is an academic social and collaboration platform that fuses professional profiles, activity feeds, subject classroom management, real-time channels, Notion-style project workspaces, and AI guidance.

---

## ✨ Key Features

- 🔄 **Multi-Role Switching**: Seamlessly switch between **Student**, **Faculty**, **College Admin**, **Alumni**, and **Company** personas.
- 📱 **Academic Activity Feed**: Share research pre-prints, code snippets, paper PDFs, upvotes & comments.
- 📋 **Notion-Style Workspaces**: Project discovery, skill matching, and interactive Kanban sprint boards.
- 📚 **Google Classroom Hub**: Course enrollment, assignment submission tracker, and faculty grading interface.
- 💬 **MS Teams Collaboration**: Topic channels, direct messaging, and HD **Virtual Study Room call modal**.
- 💼 **Opportunity Board & Alumni Network**: Internship/Fellowship/Hackathon board and 1-on-1 mentorship booking.
- 🤖 **Nexi AI Copilot**: Instant paper summarization, PyTorch debugging, and sprint roadmap generator.

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone the repository
git clone https://github.com/shreyasshinde619/Nexivora.git

# 2. Navigate to project directory
cd Nexivora

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

---

## 📦 Production Build & Deployment

```bash
# Build static site for GitHub Pages
npm run build
```
Production assets are generated in `dist/` with base path `/Nexivora/`.
